# Snakes and Ladders: Roll of Fate
A Java libGDX turn-based RPG application where players navigate an unpredictable board through dice rolls, encounter battles, events, companions, rewards, and setbacks, while making strategic choices that determine how they overcome whatever fate throws at them.

## 🚀 How to Run the Project Locally
To run the desktop application, clone this repository and use the included Gradle wrapper. Do not run it through standard Java compilation.

**Terminal Command:**
```bash
./gradlew lwjgl3:run
```
